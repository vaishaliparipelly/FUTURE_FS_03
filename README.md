# FUTURE_FS_03 – Mirosa Cafe & Kitchen Website

## Task 3 – Local Business Website & Live Pitch

A responsive website created for **Mirosa Cafe & Kitchen**, a local cafe in Himayatnagar, Hyderabad.

## Features

- Responsive design
- Home section
- About section
- Menu section
- Gallery
- Customer reviews
- Location and opening hours
- Google Maps link
- Call Now button
- Mobile navigation menu

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This website was developed as part of the **Future Interns Full Stack Web Development Internship – Task 3**.

The website provides customers with easy access to the cafe's information, menu, location, contact details and other important information.

## Disclaimer

This is a student demo website created for an internship project. It is not an official website of Mirosa Cafe & Kitchen.
